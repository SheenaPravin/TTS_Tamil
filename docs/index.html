TTS Tamil

Low-Latency Tamil, English & Tanglish Text-to-Speech System

Tamil English Tanglish Self-Hosted Real-Time

Overview

A self-hosted TTS system optimized for real-time voice agent applications in transportation and taxi contact centers. Generates natural speech for Tamil, English, and Tamil-English code-mixed (Tanglish) text without depending on third-party commercial APIs.

View on GitHub Documentation

Features

Multilingual TTS

Native support for Tamil, English, and Tanglish code-mixed speech generation.

Context-Aware Normalization

Handles booking IDs, OTPs, phone numbers, times, prices, distances, and abbreviations.

Streaming API

Time-to-first-audio optimized streaming synthesis for real-time conversations.

Concurrent Requests

Supports 15-20 concurrent TTS requests with low latency.

Quick Start

# Clone the repository
git clone https://github.com/SheenaPravin/TTS_Tamil.git
cd TTS_Tamil

# Setup (requires Python 3.11 and uv)
bash scripts/setup.sh

# Run with mock engine (no GPU needed)
TTS_USE_MOCK=true python -m src.main

# Open API docs
open http://localhost:8000/docs

API Endpoints

POST /api/v1/synthesize

Synthesize text to speech. Supports streaming mode.

POST /api/v1/normalize

Preview text normalization output.

GET /api/v1/health

Health check and service status.

GET /api/v1/model

Model information and statistics.
